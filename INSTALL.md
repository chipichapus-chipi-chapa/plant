# Как поставить «Там, где растёт» на телефон

**Сайт игры: https://chipichapus-chipi-chapa.github.io/plant/**

Эту ссылку достаточно переслать: на сайте есть кнопки «Играть», «Скачать для Android» и «Открыть в Telegram»,
а инструкция для своего телефона подсвечивается сама.

## Android: приложение-файл (APK)

1. Откройте [сайт](https://chipichapus-chipi-chapa.github.io/plant/) и нажмите **«Скачать для Android»**
   (или сразу [по прямой ссылке](https://github.com/chipichapus-chipi-chapa/plant/releases/download/android/where-it-grows.apk)) — загрузится `where-it-grows.apk`.
2. Откройте файл из уведомления или из «Загрузок».
3. Если телефон спросит — разрешите установку из браузера. Так Android реагирует на любое приложение не из магазина.
4. Нажмите **«Установить»**. На рабочем столе появится иконка сада.

**Обновление:** скачайте `where-it-grows.apk` ещё раз и установите поверх — сад сохранится (он на сервере).

### Android: через браузер (без файла)

Откройте сайт в **Chrome** → **«Играть»** → меню **⋮** → **«Установить приложение»**.
Или прямо в игре: **Настройки → «Установить на экран»**.

## iPhone (Safari)

1. Откройте [сайт](https://chipichapus-chipi-chapa.github.io/plant/) именно в **Safari**.
2. Нажмите **«Играть»**.
3. **«Поделиться»** (квадрат со стрелкой внизу) → **«На экран „Домой“»** → **«Добавить»**.

## Telegram

Откройте бота → **«Старт»** → внизу чата **«Играть»**.

## Один сад на всех устройствах

Сад заводится сам, без регистрации. Чтобы играть в один и тот же сад в приложении и в боте:
**Настройки → «Привязать Telegram»** → в открывшемся боте нажмите **«Старт»**.
Если в боте уже был сад — приложение переключится на него.

## Для того, кто ведёт проект

### Как выходят обновления

Всё происходит само после влития в `main`:

- **Сайт и игра** (`site/` → корень, `frontend/` → `app/`) — Actions → **Pages**, 1–2 минуты.
- **APK** — Actions → **Android**, файл заменяется в выпуске
  [«android»](https://github.com/chipichapus-chipi-chapa/plant/releases/tag/android).
  Ссылка на скачивание не меняется, номер версии растёт сам. На PR APK только собирается — его можно
  скачать из артефактов запуска и проверить на телефоне.
- **Сервер** — Render (см. [docs/DEPLOY.md](docs/DEPLOY.md)).

### Ключ подписи Android — сделайте резервную копию!

APK подписывается ключом, без которого телефоны **не поставят обновление поверх** старой версии.

- Ключ и пароль лежат на компьютере в папке `~/where-grows-android-key/` (в репозиторий они не попадают).
- Копия для сборки — в секретах репозитория: **Settings → Secrets and variables → Actions**
  (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`).
- Сохраните папку `~/where-grows-android-key/` на флешку или в личное облако. Если ключ потеряется,
  придётся выпустить приложение заново, и всем нужно будет удалить старую версию.

### Иконки

`npm run icons` (в `frontend/`) рисует иконки PWA, Android и картинку заставки APK из тех же спрайтов, что и атлас.
