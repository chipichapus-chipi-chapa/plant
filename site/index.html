Как поставить

Android

  1. Нажмите «Скачать для Android» — загрузится файл where-it-grows.apk.
  2. Откройте файл из уведомления или из «Загрузок».
  3. Если телефон спросит — разрешите установку из браузера (так Android встречает любое приложение не из магазина).
  4. Нажмите «Установить». Иконка сада появится на рабочем столе.

Не хочется ставить файл? Нажмите «Играть», затем в Chrome меню ⋮ → «Установить приложение».

iPhone

  1. Откройте эту страницу в Safari и нажмите «Играть».
  2. Нажмите «Поделиться» — квадрат со стрелкой внизу экрана.
  3. Выберите «На экран „Домой“» и нажмите «Добавить».
  4. Откройте сад с иконки и поверните телефон боком — так видно всю поляну.

В других браузерах на iPhone установка не работает — только Safari.

Telegram

  1. Откройте бота и нажмите «Старт».
  2. Внизу чата нажмите «Играть» — сад откроется прямо в Telegram.
  3. Уже играете в приложении? В его настройках есть «Привязать Telegram» — и сад станет общим.

Ничего ставить не нужно — работает везде, где есть Telegram.

Вопросы

Нужно ли регистрироваться?

Нет. Сад заводится сам при первом запуске. Чтобы играть в один и тот же сад с разных устройств, в настройках игры нажмите «Привязать Telegram».

Где хранится мой сад?

На сервере игры — поэтому он не пропадёт, если сменить браузер. Если сад привязан к Telegram, его можно открыть с любого телефона.

Обновления придут сами?

В браузере и Telegram — да, сразу. APK обновите, скачав файл ещё раз и установив поверх: сад сохранится.

Телефон пишет, что приложение небезопасно

Так Android предупреждает о любом файле не из магазина. Игра не просит никаких разрешений, кроме интернета.

Почему первый запуск иногда долгий?

Сервер сада живёт на бесплатном хостинге и после долгой тишины просыпается — это бывает до минуты.

Маленькие шаги тоже ведут к большим мечтам
